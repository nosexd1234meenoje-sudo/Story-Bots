# StoryBots — Director v3

Versión con Director de Historia, métricas narrativas, acontecimientos de trama y mapa de conexiones entre zonas.

## Probar localmente

Abre `public/index.html` directamente para usar el modo local.

## Servidor

`node server.js` inicia el servidor incluido. Esta versión del cliente conserva el modo local; la integración social online completa se puede adaptar en la siguiente fase.
